# 章准 · Stamp Focus

一款完全离线的 PDF 电子签名 / 盖章工具。它把签章尺寸统一成纸面毫米数，避免每次在 PDF 里凭感觉反复缩放。

## 软件说明

章准（Stamp Focus）主要解决 PDF 签字和盖章时尺寸难以统一的问题，适用于合同、审批单、采购文件、报告等需要频繁签章的场景。软件以纸面真实毫米尺寸为基准：每一枚签名或印章都有独立的专属默认尺寸，只需校准一次，之后即可在不同 PDF 中保持自然、稳定的大小；也可以框选目标签字栏，或从另一份已正确签章的参考 PDF 中量取尺寸，再通过拖动、八点拉伸和方向键进行精细调整。对于页面结构固定、需要多处签章的文件，还可以把整套签章布局保存为“签章范式”，以后打开同类 PDF 后一键放好全部章和签字。

软件支持签章素材管理、精确缩放、抓手移动页面、旋转与透明度调整，以及安装版和免安装版。所有 PDF、签名图片和导出操作均在本机完成，不会上传到服务器；开启“安全嵌入”后，签章会与页面内容合成为一体，降低被单独选中、移动或删除的风险。需要注意的是，“安全嵌入”属于页面合成保护，并不等同于使用 CA 数字证书完成的密码学电子签名。

版本新增、改进和修复记录请查看 [CHANGELOG.md](CHANGELOG.md)。

Windows 用户可从 [Releases](https://github.com/1Dingdingdang/stamp-focus/releases/latest) 下载最新版安装程序或免安装版。

## 核心用法

1. 打开 PDF。
2. 添加签名或印章图片；首次输入它在纸上的自然宽度，例如 `42 mm`。
3. 点击左侧素材，把它放到当前页；拖动位置，右下角等比例缩放，上方旋转。
4. 如果 PDF 里已有自然签名或明确的签字框，点击“框选匹配”；首次拖框后可整体移动或拉动八个控制点微调，按 Enter 确认后软件会自动等比例套入，并把结果记为当前素材的专属默认尺寸。
5. 如果要从另一份正确样本取尺寸，打开“参考 PDF 取尺寸”；拖框后同样可移动、拉伸或用方向键微调，按 Enter 确认后保存。随后点击对应签名或印章时，参考宽高会自动记为该素材的专属默认尺寸。
6. 需要放大查看时，可直接输入缩放百分比并按 Enter；选择“抓手”后拖动页面即可移动视野。
7. 对于固定格式的文件，先把全部章和签字摆到正确页码与位置，再点击左侧“签章范式”旁的保存按钮并命名。以后打开同类 PDF，点击该范式即可一键放置整套签章。
8. 点击“导出已签章 PDF”。

框选确认、页面拖拽缩放或右侧输入宽度后，尺寸都会自动保存到对应的签名或印章；调整其中一个素材不会改变其他素材。下次点击左侧素材时，软件会直接使用它自己的默认宽高。

签章范式会保存每个素材的页码、相对页面位置、实际毫米尺寸、旋转角度和透明度。套用到页面尺寸略有差异的同类 PDF 时，位置会按页面比例适配，签章的真实毫米大小保持不变；如果当前素材库缺少范式所需的章或签名，或者目标 PDF 缺少对应页码，软件会明确提示。范式依赖本机素材库，建议为长期使用的素材保留稳定且易识别的名称。

## 隐私与安全

- 软件没有账号、遥测、分析或上传接口；运行时代码不会向外部服务器发起网络请求。
- PDF 内容仅在内存中处理；签章图片、真实尺寸、参考尺寸和签章范式保存在本机应用存储中。
- Electron 桌面版启用了沙箱、上下文隔离、内容安全策略，并禁止页面跳转到外部地址。
- “安全嵌入”会把签章与页面合成，降低签章被单独修改的风险，但不等同于 CA 数字证书签名。
- Windows 安装包和免安装包目前未使用商业代码签名证书，系统可能提示“未知发布者”。请从本仓库的 Releases 下载，并使用随版本提供的 `SHA256SUMS.txt` 核对文件。

安全问题报告方式请查看 [SECURITY.md](SECURITY.md)。

## 本地运行

需要 Node.js 20 或更新版本：

```powershell
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。

## Windows 桌面版

```powershell
npm run electron:dev
```

生成安装包和免安装版：

```powershell
npm run electron:pack
```

输出位于 `release/`。

## 验证

```powershell
npm test
npm run build
```

项目自带 `fixtures/size-test.pdf`（含一个精确的 50 × 20 mm 测试框）和测试签名，可用于检查尺寸匹配。
